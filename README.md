# Todo Workshop

A small task list used in the Git Academy workshop to practise the daily Git and GitHub workflow.

## How to run

Open `index.html` in a browser. Once issue #4 is done, use the local server: `./scripts/serve.sh`.

## How to contribute

1. Pick an issue from the board and move it to **In Progress**.
2. Create a branch from an up-to-date `main`: `feature/<issue>-<short-description>` (or `fix/`, `hotfix/`, `docs/`, `chore/`).
3. Commit with [Conventional Commits](https://www.conventionalcommits.org/): `feat(scope): description #<issue>`.
4. Push the branch and open a pull request whose description says `Closes #<issue>`.
5. After review, the pull request is merged with **Create a merge commit**.
